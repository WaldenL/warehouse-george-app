Bottle processing pipeline · test bench

Select 1–12 photos of ONE bottle. Originals are archived unchanged. Each working image is cropped, gently balanced and optionally background-isolated without generative reconstruction. OpenAI examines all working images together; the thumbnail is derived directly from the primary working photo, without generative AI. No inventory data is modified.

If automatic segmentation is unavailable, the test continues with crop and exposure corrections and clearly reports the fallback.
